# Instance

> PostgreSQL instance-level monitoring dashboards

---

LLMS index: [llms.txt](/llms.txt)

---

PostgreSQL instance-level monitoring dashboards, including:

- [PGSQL Instance](/docs/pgsql/dashboard/instance/pgsql-instance): Main dashboard for a single PGSQL instance
- [PGRDS Instance](/docs/pgsql/dashboard/instance/pgrds-instance): RDS version of PGSQL Instance, focusing on PostgreSQL-native metrics
- [PGCAT Instance](/docs/pgsql/dashboard/instance/pgcat-instance): Instance info retrieved directly from database catalog
- [PGSQL Persist](/docs/pgsql/dashboard/instance/pgsql-persist): Persistence metrics: WAL, XID, checkpoint, archive, IO
- [PGSQL Proxy](/docs/pgsql/dashboard/instance/pgsql-proxy): Detailed metrics for a single HAProxy load balancer
- [PGSQL Pgbouncer](/docs/pgsql/dashboard/instance/pgsql-pgbouncer): Metrics overview for a single Pgbouncer connection pooler
- [PGSQL Session](/docs/pgsql/dashboard/instance/pgsql-session): Session and active/idle time metrics for a single instance
- [PGSQL Xacts](/docs/pgsql/dashboard/instance/pgsql-xacts): Transaction, lock, TPS/QPS related metrics
- [PGSQL Exporter](/docs/pgsql/dashboard/instance/pgsql-exporter): Self-monitoring metrics for Postgres and Pgbouncer exporters
