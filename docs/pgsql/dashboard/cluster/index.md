# Cluster

> PostgreSQL cluster-level monitoring dashboards

---

LLMS index: [llms.txt](/llms.txt)

---

PostgreSQL cluster-level monitoring dashboards, including:

- [PGSQL Cluster](/docs/pgsql/dashboard/cluster/pgsql-cluster): Main dashboard for a PGSQL cluster
- [PGRDS Cluster](/docs/pgsql/dashboard/cluster/pgrds-cluster): RDS version of PGSQL Cluster, focusing on PostgreSQL-native metrics
- [PGSQL Activity](/docs/pgsql/dashboard/cluster/pgsql-activity): Session/load/QPS/TPS/locks for PGSQL cluster
- [PGSQL Replication](/docs/pgsql/dashboard/cluster/pgsql-replication): Replication, slots, and pub/sub for PGSQL cluster
- [PGSQL Service](/docs/pgsql/dashboard/cluster/pgsql-service): Service, proxy, routing, and load balancing for PGSQL cluster
- [PGSQL Databases](/docs/pgsql/dashboard/cluster/pgsql-databases): Database CRUD, slow queries, and table statistics across all instances
- [PGSQL Patroni](/docs/pgsql/dashboard/cluster/pgsql-patroni): HA status and Patroni component status for cluster
- [PGSQL PITR](/docs/pgsql/dashboard/cluster/pgsql-pitr): PITR context for point-in-time recovery assistance
