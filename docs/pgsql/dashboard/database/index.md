# Database

> PostgreSQL database-level monitoring dashboards

---

LLMS index: [llms.txt](/llms.txt)

---

PostgreSQL database-level monitoring dashboards, including:

- [PGSQL Database](/docs/pgsql/dashboard/database/pgsql-database): Main dashboard for a single PGSQL database
- [PGCAT Database](/docs/pgsql/dashboard/database/pgcat-database): Database info retrieved directly from database catalog
- [PGSQL Tables](/docs/pgsql/dashboard/database/pgsql-tables): Table/index access metrics within a single database
- [PGSQL Table](/docs/pgsql/dashboard/database/pgsql-table): Detailed info for a single table (QPS/RT/index/sequence...)
- [PGCAT Table](/docs/pgsql/dashboard/database/pgcat-table): Detailed table info from database catalog
- [PGSQL Query](/docs/pgsql/dashboard/database/pgsql-query): Detailed info for a query type (QPS/RT)
- [PGCAT Query](/docs/pgsql/dashboard/database/pgcat-query): Query details from database catalog
- [PGCAT Locks](/docs/pgsql/dashboard/database/pgcat-locks): Activity and lock wait info from database catalog
- [PGCAT Schema](/docs/pgsql/dashboard/database/pgcat-schema): Schema info from database catalog
