Metrics

Current PGSQL recording rules, raw metric sources, and historical scrape samples.

This page separates raw metrics from scrape endpoints from recorded metrics computed by vmalert. files/victoria/rules/pgsql.yml defines 402 recording rules. Common examples appear below; the Recording Metric Index lists every name and expression. Query recorded metrics in VictoriaMetrics, not at an exporter’s /metrics endpoint.

Raw metrics vary with software versions, collectors, privileges, instance roles, and runtime state. Historical scrape samples are retained for identifying metrics, not as a complete interface for the current version.

Raw PostgreSQL and PgBouncer metrics are defined in pg_exporter.yml and pgbouncer_exporter.yml, respectively. Patroni, pgBackRest Exporter, and exporter runtime metrics come from their own implementations. SQL collectors are selected by min_version / max_version, role tags, and probe queries; they do not all run on the same instance.
