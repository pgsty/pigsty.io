Metrics

Current REDIS recording rules, raw metric sources, and historical scrape samples. with explanations

This page separates raw metrics from scrape endpoints from recorded metrics computed by vmalert. files/victoria/rules/redis.yml defines 96 recording rules. Common examples appear below; the Recording Metric Index lists every name and expression. Query recorded metrics in VictoriaMetrics, not at an exporter’s /metrics endpoint.

Raw metrics vary with software versions, collectors, privileges, instance roles, and runtime state. Historical scrape samples are retained for identifying metrics, not as a complete interface for the current version.

Current Recording Rules

ins, cls, and env refer to instance, cluster, and environment levels; actual aggregation labels depend on each expression. See Metric Definitions and Counts for differences in types and counts between recorded and raw metrics.
