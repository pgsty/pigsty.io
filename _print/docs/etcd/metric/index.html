Metrics

Current ETCD recording rules, raw metric sources, and historical scrape samples.

This page separates raw metrics from scrape endpoints from recorded metrics computed by vmalert. As of 2026-10-13, files/victoria/rules/etcd.yml defines 9 recording rules. The table lists each name and expression. Recorded metrics come from rule evaluation and are not found at an exporter’s /metrics endpoint.

Raw metrics vary with software versions, collectors, privileges, instance roles, and runtime state. Historical scrape samples are retained for identifying metrics, not as a complete interface for the current version.

Current Recording Rules

Expressions retain their source semantics. ins, cls, and env generally indicate instance, cluster, and environment aggregation levels; actual retained labels depend on by / without and vector-matching clauses. Recording rules have no independent Prometheus TYPE metadata and should not all be labeled Counter or Gauge.

In addition, etcd_up come from Infra’s shared liveness recording rules. They are excluded from the module rule count above and are not raw exporter metrics. They reflect scrape status and do not replace functional service checks.
