## Build

You can build the RPM / DEB packages for `hunspell` using `pig build`:

```bash
pig build pkg hunspell         # build RPM / DEB packages
```


## Install

You can install `hunspell` directly. First, make sure the [**PGDG**](/docs/repo/pgdg) and [**PIGSTY**](/docs/repo/pgsql) repositories are added and enabled:

```bash
pig repo add pgsql -u          # Add repo and update cache
```

Install the extension using [**pig**](https://pig.pgsty.com) or `apt/yum/dnf`:

```bash {tab="Install" group="install-pig-dnf-apt" value="install"}
pig install hunspell;          # Install for current active PG version
```

```bash {tab="pig" value="pig"}
pig ext install -y hunspell -v 18  # PG 18
pig ext install -y hunspell -v 17  # PG 17
pig ext install -y hunspell -v 16  # PG 16
pig ext install -y hunspell -v 15  # PG 15
pig ext install -y hunspell -v 14  # PG 14
```

```bash {tab="dnf" value="dnf"}
dnf install -y hunspell_18       # PG 18
dnf install -y hunspell_17       # PG 17
dnf install -y hunspell_16       # PG 16
dnf install -y hunspell_15       # PG 15
dnf install -y hunspell_14       # PG 14
```

```bash {tab="apt" value="apt"}
apt install -y postgresql-18-hunspell   # PG 18
apt install -y postgresql-17-hunspell   # PG 17
apt install -y postgresql-16-hunspell   # PG 16
apt install -y postgresql-15-hunspell   # PG 15
apt install -y postgresql-14-hunspell   # PG 14
```

CREATE EXTENSION hunspell_cs_cz;

## Usage

> [hunspell_cs_cz: Czech Hunspell dictionary for PostgreSQL](https://github.com/postgrespro/hunspell_dicts)

Czech Hunspell dictionary and text search configuration for PostgreSQL full-text search.

```sql
CREATE EXTENSION hunspell_cs_cz;

SELECT ts_lexize('czech_hunspell', 'příběhy');

SELECT to_tsvector('czech_hunspell', 'příběhy');
```

This extension provides the `czech_hunspell` dictionary and text search configuration.
