`pg19` is the single-node PostgreSQL 19 Beta evaluation template. It follows the `meta` topology, enables the `beta` repository, and deliberately limits packages and extensions.


--------

## Overview

- Config Name: `pg19`
- Node Count: Single node
- PostgreSQL Version: `19` Beta
- Use Cases: New-version evaluation and compatibility testing
- Related: [`meta`](/docs/conf/meta/), [`pgsql`](/docs/conf/pgsql/)

Usage:

```bash
./configure -c pg19 [-i <primary_ip>]
```

## Explanation

Important defaults and limitations:

- `node_repo_modules: node,infra,pgsql,beta` obtains PG19 packages from the PGDG Beta repository
- `pg_packages` contains only the kernel, Patroni, PgBouncer, exporter, and VIP components
- `pg_extensions: []` installs no extension packages
- `pgbackrest_enabled: false` also disables the pgBackRest exporter and default full-backup job
- INFRA, ETCD, PGSQL, and optional pgAdmin remain available for a single-node evaluation

This is a Beta evaluation configuration, not a production template. Do not treat `-v 19` on an ordinary template as a production-ready PG19 deployment; validate extensions, backup, and upgrade procedures separately.
